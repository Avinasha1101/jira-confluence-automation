## Quick Reference: All Decisions

### 🔴 CRITICAL Issues (2) - RESOLVED

#### 1. MCP Server Configuration
**Decision:**
- Use official Atlassian MCP servers only (no custom)
- Add MCP setup to Phase 0 tasks
- Provide setup instructions in README
- If MCP not configured: Show installation instructions (not just fail)

#### 2. Custom Field ID Discovery
**Decision:**
- Manual discovery acceptable for v1.0
- If field IDs wrong: Warn but continue (skip story points, use issue count)
- No validation on first run
- Document in README with screenshots

### 🟡 HIGH Priority Issues (14) - RESOLVED

#### 3. Confluence Page Creation Strategy
**Decision:**
- Create under specific parent page (add `parent_page_id` to config - REQUIRED)
- If no create permission: Fail with error + instructions
- No automatic labels/metadata

#### 4. Status Mapping Validation
**Decision:**
- Case-insensitive status matching
- Unmapped statuses: Fail with validation error listing all unmapped
- Overlapping statuses: Reject during validation (error)

#### 5. Blocker Reason Extraction Logic
**Decision:**
- Search: Issue description first, then comments as fallback
- Search for keywords: "block", "blocked", "blocker" (case-insensitive)
- If not found: Display "Reason not specified"
- Max length: First 200 characters

#### 6. Report Positioning Contradiction
**Decision:**
- Use "Prepend" terminology consistently (add to TOP)
- New reports appear above older reports (most recent first)

#### 7. Metric Fallback Behavior
**Decision:**
- If ANY issue lacks story points → fallback entire sprint to issue count
- Prompt PM for confirmation: "Story points missing. Use issue count instead? Y/N"
- If fallback: Use full issue count calculation

#### 8. "Completed This Week" Time Window
**Decision:**
- Time window: Sprint start to NOW (if active) OR full sprint period (if closed)
- Multiple reports in same sprint: Show cumulative progress

#### 9. Logging Strategy
**Decision:**
- Log levels: DEBUG, INFO, WARN, ERROR
- Default level: DEBUG (verbose for early adoption)
- Rotation: Daily rotation, keep 30 days
- Sensitive data: Log everything (no redaction for debugging)

#### 10. Rate Limiting Strategy
**Decision:**
- No client-side rate limiting (rely on server errors + retry)
- No caching (always fetch fresh data)
- Large sprints: Paginated sequential fetching

#### 11. Confluence Parent Page
**Decision:**
- `parent_page_id` is REQUIRED in config
- Document how to find parent page ID in README

#### 12. Epic Grouping Sort Order
**Decision:**
- Case-insensitive alphabetical sort
- Natural sort for numeric prefixes (1, 2, 10)
- Tie-breaker: Epic key

#### 13. Empty Epic Name Handling
**Decision:**
- Display as: "PROJ-100 (No Name)"
- Log warning for missing epic names

#### 14. Error Recovery Procedures
**Decision:**
- Partial publish: Tool detects and retries automatically
- Provide `/weekly-report-rollback` command

### 🟢 MEDIUM Priority Issues (19) - RESOLVED

#### 15. Progress Bar Format
**Decision:**
- Fixed 20-character width
- Use `█` (filled) and `░` (empty)

#### 16. Configuration Validation Timing
**Decision:**
- Validate on every `/weekly-report` run
- Non-critical warnings: Display warning and prompt PM to confirm

#### 17. Draft File Naming Collision
**Decision:**
- Auto-increment naming: `weekly-report-2024-12-25-1.md`, `-2.md`, etc.
- Auto-delete drafts older than 30 days

#### 18. Health Threshold Constraints
**Decision:**
- Enforce ranges: green_max (5-50), yellow_max (green_max+1 to 100)
- Reject if green_max >= yellow_max

#### 19. Timezone Format
**Decision:**
- Support IANA timezone names only
- Reject abbreviations (ambiguous)
- Validate against known timezone database

#### 20. Narrative Generation
**Decision:**
- Template-based generation for v1.0 (not AI)
- Template: "[Health]. Team completed [X] of [Y] [metric]. [Highlight]. [Blocker status]."
- Defer AI to v1.1

#### 21. Large Sprint Handling
**Decision:**
- Warn if sprint >100 issues
- Fail if >500 issues (hard limit)

#### 22. Data Sanitization
**Decision:**
- Include: key, summary, epic name, story points, blocker reason (200 chars)
- Exclude: full descriptions, internal comments (except blocker), assignee details
- Strip @mentions

#### 23. Version in Reports
**Decision:**
- Add footer: "Generated by Manager.AI v1.0 on [timestamp]"
- Include tool version in metadata

#### 24. Page Permissions Error
**Decision:**
- Fail with clear error if no edit permission
- Save draft locally

#### 25. Retry Backoff Parameters
**Decision:**
- Base: 1s, Exponential: 2x (1s, 2s, 4s)
- Max delay: 10s
- Jitter: ±50%
- Max attempts: 3

#### 26. Status Overlap Policy
**Decision:**
- Strictly forbid overlapping mappings
- Validation error if overlap
- Case-insensitive detection

#### 27. Accessibility Standards
**Decision:**
- Text equivalents for emojis
- Health: emoji + text
- WCAG 2.1 Level AA
- Screen reader friendly

#### 28-34. Low Priority Issues
**Decision:** All approved with recommended defaults
- Log retention: 30 days
- Observability: Log metrics, no external monitoring v1.0
- Security testing: Phase 5, npm audit, test expired tokens
- Architecture diagrams: Add to spec
- FAQ: Add to README from UAT
- Troubleshooting tree: Create decision tree
- Load testing: 10/50/100/200 issue sprints

## Validation Rules (Clarified)

### Configuration Validation
- Run on every `/weekly-report` execution
- Case-insensitive status matching
- No overlapping status mappings
- Health thresholds: 5 ≤ green_max < yellow_max ≤ 100
- Timezone: IANA format only
- parent_page_id: REQUIRED

### Data Validation
- Unmapped statuses: FAIL with list of unmapped
- Missing custom fields: WARN and fallback to issue count
- Empty sprint: Allow (generate report with "No issues" messages)

## Behavior Clarifications

### Time Windows
- **"Completed This Week":** Sprint start to NOW (if active) OR full period (if closed)
- **Multiple Reports:** Cumulative progress (not delta)
- **Timezone:** All dates in UTC internally, display in config timezone

### Epic Grouping
- **Sort:** Case-insensitive, natural numeric sort
- **Tie-break:** By epic key
- **Unassigned:** Always last
- **Empty epic names:** Display as "EPIC-KEY (No Name)" + log warning

### Blocker Extraction
1. Search issue description for "block*" keywords
2. If not found, search last 10 comments
3. If found, extract first 200 characters
4. If not found, display "Reason not specified"

### Metric Fallback
1. Check if ANY issue lacks story points
2. If yes, prompt PM: "Story points missing. Use issue count? Y/N"
3. If confirmed, calculate using issue counts
4. If declined, abort report generation

### Draft Management
- Filename: `weekly-report-YYYY-MM-DD-N.md` (auto-increment N)
- Auto-delete drafts >30 days old
- Save on: Cancel, Publish failure

## Error Handling (Clarified)

### MCP Errors
- **Not authorized:** Show install + auth instructions
- **Timeout:** Retry 3x with exponential backoff (1s, 2s, 4s)
- **Rate limit:** Rely on retry (no client-side limiting)

### Confluence Errors
- **No permission:** Fail with error, save draft, show admin contact
- **Version conflict:** Auto-retry (detect and fetch latest version)
- **Partial publish:** Auto-retry (tool detects incomplete state)

### Configuration Errors
- **Missing file:** Show example config + setup instructions
- **Invalid JSON:** Show syntax error location
- **Validation failure:** List all errors at once (not one-by-one)
- **Warnings:** Prompt for confirmation before continuing
